# Cajun's Tarkov Contracts

Static GitHub Pages website for a Tarkov-inspired stream event.

## Features

- Clean tactical admin dashboard layout
- New event name: Cajun's Tarkov Contracts
- Logo included as `logo.png`
- Admin can mark streamers as Playing or Not Playing without deleting them
- Streamers use a cleaner entry page to submit level and money
- Admin randomizes only active and ready streamers
- Dashboard shows assigned gun, gear, estimated cost, and contract twist

## Upload

Upload all files to the root of your GitHub repository:

- `index.html`
- `styles.css`
- `script.js`
- `logo.png`
- `README.md`

GitHub Pages should be set to deploy from `main` and `/root`.

## Note

This version still uses browser local storage. For true live multi-user sync, the next step is adding a backend such as Firebase or Supabase.
